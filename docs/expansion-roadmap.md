# 拡張ロードマップ（5エージェント多角分析の集約）

作成日: 2026-05-10
依頼: 「ゲーム全体を見渡して面白くできそうな要素」
分析: 5並列エージェント（既存資産発掘 / 他ゲーム輸入 / 新ステージ&長尺化 / メタ進行 / 演出フィール）

---

## 共通指摘された弱点

1. **演出が薄味**: 踏みつけ・パワーアップ・ゴール時の効果が地味（既存 `G.shakeX/Y` 機構があるのに踏みつけで未使用）
2. **死にコード**: `G.darkMode` / `G.tideMode` / `G.windZones` / `G.shield` / `G.sandstormMode` が定義のみ or 1ステージ限定
3. **メタ進行が浅い**: clearedStages しか永続化されず、再プレイ動機が ★スターコインだけ
4. **4-1 が短すぎる**: W=3900px（他ステージ平均7200pxの50%）

---

## 視点別の代表案（重複統合済み）

| 視点 | 一押し |
|---|---|
| 既存資産活用 | 風ゾーン可視化（windParticles配列が空のまま）/ シールド未実装ショップ品 |
| 他ゲーム輸入 | **ワンダーフラワー**（ステージ中盤でルール豹変）/ リプレイゴースト |

## 路線別ロードマップ（4本立て、組み合わせ可）

### 🅐 即効派手化【1〜2時間 / 規模 small×4】
気持ちよさを底上げ。今すぐ体感が変わる。

- ヒットストップ 3F（敵踏み・ブロック破壊）
- パワーアップ取得時の白フラッシュ＋暗転
- コイン磁石の曲線吸着＆色分け数値ポップ
- グローバル達成度ダッシュボード（スタート画面）

### 🅑 新鮮さ最大化【半日〜1日 / 規模 med】
**ワンダーフラワー** 1点突破（Mario Wonder式）。
各ステージに1個配置→取得で30秒だけルール豹変：

ルール候補（3〜5個から選定）
- 重力反転（30秒）
- 全敵2倍サイズ（巨大化）
- コインが自動追尾
- シルエットモード（地形と敵が真っ黒）
- スクロール反転（右→左進行）
- 全敵スロー（0.5倍速）
- パイプから無限コイン噴出
- 全マリオ高速化（dash常時）

→ これだけで「全24ステージ再訪したくなる」破壊力。

### 🅒 やりこみ寿命3倍【1〜2日 / 規模 small×3】
- チャレンジスタンプ 4種×24（ノーダメ / 全コイン / タイム以下 / ノーキル）→ 96スタンプ
- タイムアタックモード ＋ localStorageベストタイム

### 🅓 ボリューム拡張【2〜3日 / 規模 med-large】
- World 9 (4ステージ): 風の神殿 / コイン回廊 / ペンギン将軍ボス / 夜の1-1リミックス
- ボスラッシュEX: 歴代クッパ＋ボス連戦

## 推奨着手順（個人的推し）

**🅑 ワンダーフラワー → 🅐 即効派手化** がコスパ最高。

理由:
- 🅑 は 1 個実装すれば既存24ステージ全部が「新作」になる
- その後 🅐 で底上げすれば、ワンダー中の演出も派手になる相乗効果
- 🅒 🅓 は本編が面白くなった後でやる方が楽しい

避けたい: いきなり 🅓 World 9 を作っても本編の演出が薄味のままだとボリューム水増しに見える。
